# BLACKPINK K-POP Songs Analysis

## Project Overview
This project analyzes BLACKPINK's K-POP songs using data analysis and visualization techniques.

The analysis focuses on song popularity, chart performance, content type, album characteristics, momentum, fandom engagement, and other performance indicators.

## Objectives
- Analyze song popularity and chart performance
- Compare single and album tracks
- Study content attributes
- Measure momentum and comeback strength
- Analyze fandom engagement
- Identify patterns and trends in BLACKPINK's music performance

## Tools & Technologies
- Microsoft Excel
- Power BI
- Data Analysis
- Data Visualization
- GitHub

## Key Analysis
The project includes analysis of:
- Popularity Score
- Chart Rank
- Content Type
- Momentum Analysis
- Momentum Spike Measurement
- Momentum Sustainability
- Initial Rank
- Single vs Album Track Performance
- Fandom Engagement

## Dashboard
An interactive Power BI dashboard was created to visualize the key findings and performance trends.

## Dataset
The dataset contains information about BLACKPINK songs including:
- Song Name
- Artist
- Release Date
- Chart Position
- Popularity Score
- Duration
- Album Type
- Total Tracks
- Explicit Content
